# Corpus Harvest Handoff 1.0.0

Frozen EncyKlopedia → Da’at handoff contract.

EncyKlopedia owns source discovery/acquisition and immutable evidence packaging. Referent registries emitted here are **candidate identity registries**, not validated Kristal knowledge. Da’at performs the mapping to the installed Kristal contract.

Frozen compatibility target:
- Kristal: `5.0.0-rc.3`
- Referent Registry: `kristal.referent-registry/1.0.0`

The contract is deliberately domain-neutral. A people-first scope is one discovery strategy, not a universal rule.
