# Guide utilisateur

## Modèle mental

Konstellation vous permet de :

1. **sélectionner** un territoire de connaissance avec recherche/facettes ;
2. **explorer** ce territoire avec une recette adaptée ;
3. **inspecter** une entité, relation, assertion, evidence ou provenance ;
4. **pivoter** explicitement vers une nouvelle sélection.

## Les vues adaptatives

Les boutons proposés dépendent de la structure visible. Par exemple : Chronologie, Dépendances, Parcours, Boucles, Preuves ou Traçabilité.

Une vue recommandée n'est pas une vérité : elle indique seulement qu'une structure du corpus se prête bien à cette exploration.

## Lens

Une Lens change la perspective, les facettes et les labels. Elle ne change pas vos permissions.

## Reader Policy

Une Reader Policy change ce que vous avez le droit de voir. Lorsque la policy change, les résultats et vues sont recalculés.

## Adaptive / pinned

- adaptive : Konstellation peut adapter la recette lorsque le contexte change ;
- pinned : votre recette reste sélectionnée tant qu'elle reste applicable.

## Sources et provenance

L'inspecteur distingue autant que possible evidence et provenance. Les divergences explicites sont affichées sans arbitrage automatique.
